## lab1_dart

Проект был нацелен на создание консольного приложения анализирующего статистику учеников.
Колесников Владислав ИСП-241

Запуск:

1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab1_dart`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

В этой лабораторной я изучил основы языка dart и создал мини консольное приложение.

1. В Dart тип проверяется ещё при компиляции, а в Python — только во время выполнения. За счёт этого ошибки видно сразу в редакторе, а не когда программа уже запущена.

2. String — переменная обязана хранить строку, а String? может хранить строку или null. Компилятор заставляет проверить значение на null, прежде чем его использовать.

3. final запрещает менять переменную на уровне языка — если попробуешь присвоить новое значение, код просто не скомпилируется.

4. Позиционный параметр передаётся по порядку, а именованный — с указанием имени, и required делает его обязательным. Вызов выглядит так: greet(name: "Иван");
